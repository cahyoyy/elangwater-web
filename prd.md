# PRD - Website Company Profile Elang Water

## 1. Overview

### Nama Project

Website Company Profile Elang Water

### Tujuan Website

Membangun kepercayaan pelanggan dan meningkatkan penjualan dengan menampilkan kelengkapan produk, berbagai merek yang tersedia, testimoni pelanggan, serta kemudahan pemesanan melalui WhatsApp.

### Target Pengguna

* Pemilik warung
* Pemilik toko kelontong
* Pemilik minimarket
* Pemilik kafe dan restoran
* Kantor dan instansi
* Sekolah dan kampus
* Hotel dan penginapan
* Event organizer
* Rumah tangga

### Karakter Pengguna

Beragam usia dan latar belakang pendidikan.

Website harus:

* Mudah dipahami dalam 5 detik pertama
* Tidak terlalu banyak teks
* Mengutamakan visual produk
* Tombol WhatsApp selalu terlihat
* Nyaman dibaca di HP maupun desktop

# 6. Mobile First Requirements

Prioritas utama mobile.

Target:

70% pengguna menggunakan smartphone.

### Mobile Rules

Menu hamburger.

Button WhatsApp selalu terlihat.

Ukuran font minimum 16px.

Jarak antar elemen nyaman disentuh.

Semua slider dapat swipe.

Tidak ada teks terlalu panjang.

---

# 7. Performance Requirements

LCP < 2.5 detik

CLS < 0.1

Optimasi gambar WebP.

Lazy loading gambar.

Video menggunakan thumbnail sebelum dimainkan.

Skor Lighthouse minimal 90.

---

# 8. Conversion Requirements

Tombol WhatsApp muncul pada:

* Header
* Hero
* Produk
* Setelah Testimoni
* CTA Penutup
* Floating WhatsApp

Target utama seluruh website:

Mengarahkan pengunjung untuk menghubungi Elang Water melalui WhatsApp.
